# Daily-Paper-Assistant · 科研文献阅读工作台

本地使用的文献发现、翻译、收藏与 AI 解读工具。无需注册账号，资料和模型密钥保存在自己的电脑上。

## 下载与启动

**普通用户请到 [Releases 下载正式安装包](https://github.com/Jessieimsorry/Daily-Paper-Assistant/releases/latest)，不必下载整个源码仓库。**

1. 安装 [Node.js 24 LTS](https://nodejs.org/)，安装时保留加入 PATH。
2. 完整解压 `Daily-Paper-Assistant-版本号.zip`。
3. Windows 双击 `启动工作台.cmd`；macOS 双击 `启动工作台.command`。Linux 运行 `bash start.sh`。
4. 首次启动会安装 Excel 依赖并打开浏览器。启动窗口保持打开。

macOS 如阻止运行下载的启动脚本，可在已解压目录中打开终端，运行 `npm start`。

## 已经在用旧版？

下载新版、解压、双击启动即可沿用固定目录中的资料。升级会先备份，再切换程序；新版启动失败时自动恢复。

- 支持升级的旧版正在运行：新版启动器会在无采集或模型任务时安全切换。
- 更早的旧版仍在运行：按提示关闭旧启动窗口，再次启动新版。
- 旧资料仍在原来的程序目录：先阅读 [升级与迁移指南](docs/升级指南.md)，不要删除旧文件夹。
- 不需要重新填写密钥，也不要删除个人数据目录。

## 可以做什么

- 按可自定义的研究方向发现论文，筛选、浏览、收藏与记录阅读判断。
- 完整显示篇名、关键词、摘要，支持多语翻译和护眼阅读设置。
- 使用不同模型连接，运行 AI 解读、智能体与顺序流程。
- 导入期刊目录；管理技术前沿、科学进展；导出个人资料与收藏引用。

AI 译文与解读需自行配置模型服务。期刊等级需导入合法取得的目录；公开接口没有摘要或全文时，不会伪造材料。
