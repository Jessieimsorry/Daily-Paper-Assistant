# 隐私与发布

发布只复制程序、启动器、模板、公开说明、隔离测试和脱敏演示图片。数据目录及其符号链接、旧数据副本、用户 API、settings/secrets、数据库、全文、译文缓存、日志、收藏、个人截图、机构期刊目录均排除。

本机阅读数据与代码独立。普通配置响应不能返回密钥；模型连接仅报告是否配置。调用模型前应了解材料将发往自己填写的接口，程序不擅自切换厂商。

发布脚本逐个扫描允许文件。若已有 Git 历史，还需审查历史；发布目录从新副本开始，不携带本机历史。敏感信息检查与允许清单是防误传措施，发布前仍应人工核对文件清单。

恢复：停止服务，恢复备份代码并使用备份的数据库／数据目录；不要在服务运行时覆盖 SQLite 文件。新版迁移保留原有行，回退代码时应使用相应数据备份以免旧程序误解新增状态。
