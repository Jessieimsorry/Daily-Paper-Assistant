# 第三方依赖

Excel 导入使用 ExcelJS 4.4.0（MIT）：https://github.com/exceljs/exceljs。

通过 npm 官方注册源安装，以 package-lock.json 固定依赖。为避开 uuid 旧版的已知问题，覆盖使用 uuid 11.1.1。依赖许可证可在安装后的 node_modules 对应包中查看。发布不捆绑 node_modules，启动时通过 npm 安装。

项目更新不自动拉取 GitHub，也不自动更新 npm 依赖；维护者需要检查更新、运行测试并发布新版本。更新前备份数据，回退使用原版本及兼容的数据备份。修改运行中的程序后需重启服务。
